Don't lose the afternoon to it.

Carino Setup is one command. It reads the machine it is running on — operating system, distribution family, hardware — then installs the drivers, codecs and repositories that match it, and the software for whatever the machine is actually for: 15 purpose profiles from Gaming to Medical Imaging. Linux, Windows and macOS, with nothing to install first. It refuses the distributions it cannot do honestly and prints the reason, and a dry run shows you every privileged command instead of running it.

Pick the machine you are setting up.

$ bash <(curl -s https://setup.carino.systems/setup.sh)

Fedora is what it is built and tested on, including the atomic variants. Debian, Ubuntu, Arch, RHEL, CentOS and their derivatives are supported too.

PS> iwr -useb https://setup.carino.systems/setup.ps1 | iex

Run Terminal as Administrator — the script stops without it. It detects your build, applies the Windows 10 or 11 tweaks, then asks which profile to install and installs it with winget.

$ bash <(curl -s https://setup.carino.systems/macos.sh)

Installs Homebrew if missing, then a Basic, Gaming, Corporate or FOSS profile. Apple Silicon and Intel.

What it does (and refuses)

What it does

  • Reads the machine before it touches it. Operating system, distribution family and graphics hardware, then it installs what matches instead of a fixed list.
  • 15 purpose profiles. Gaming, Corporate, Development, Design, Cybersecurity, Forensics, Scientific, Robotics, Medical Imaging and more — native packages and the Flatpaks that belong with them.
  • Twelve desktops, where the family has them. GNOME through Niri. Where a family has no package list for one, the builder names it and says why rather than letting the install fail halfway.
  • Rehearses on request. A dry run prints every privileged command it would run and installs nothing.
  • Installer menus in eight languages. English, Japanese, Russian, Spanish, Finnish, Chinese, Korean and Hebrew.

What it will not do

  • It is not a configuration manager. It installs once. It does not converge a machine to a described state, it does not run again on a schedule, and running it twice does not undo the first run. Ansible and Salt still have a job.
  • It is not sandboxed. It runs privileged commands and adds third-party repositories — RPM Fusion, EPEL, Remi, Flathub, LibreWolf, AnyDesk. Read the dry run before you run the real one.
  • It is not universal, and it says so. A list of distributions is refused by design, each with the reason printed. Source-based, musl, non-systemd and declarative systems are not near misses; supporting them would be a different tool.
  • It is not a backup. Run it on a fresh install, not on a machine carrying work you have not copied off somewhere else.

Every distribution it knows

Fedora family — Fedora, Nobara, Risi, Ultramarine, and the atomic variants Silverblue, Kinoite, Bazzite, Bluefin, Aurora and Universal Blue.

Debian family — Debian, Ubuntu and its flavours, Mint, LMDE, Pop!_OS, Zorin, elementary, Kali, Parrot, Devuan, Raspberry Pi OS, MX, Deepin, KDE neon and more.

Enterprise — RHEL, CentOS Stream and the rebuilds: Rocky, AlmaLinux, Oracle Linux and others. Arch family — Arch, Manjaro, EndeavourOS, Garuda, CachyOS, ArcoLinux, RebornOS, Archcraft. Amazon Linux, headless only. openSUSE is still under test.

Refused by design, each with a reason the script prints: SteamOS, Artix, Parabola, Gentoo, Slackware, NixOS, Guix, Alpine, Void, Clear Linux, Solus, Qubes, Mageia, OpenMandriva, Chimera and the transactional openSUSE variants.

The Plan Builder prints each of those reasons in full — pick the distribution there to read the one you came for.
