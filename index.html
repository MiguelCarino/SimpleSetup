Carino Systems · Universal OS Automation

Setup

One command turns a fresh install into a usable machine. Linux, Windows and macOS.

$ bash <(curl -s https://setup.carino.systems/setup.sh)

Built and tested on Fedora, including the atomic variants. Debian, Ubuntu, Arch, RHEL, CentOS and their derivatives are supported too.

Every distribution it knows about

Fedora family — Fedora, Nobara, Risi, Ultramarine, and the atomic variants Silverblue, Kinoite, Bazzite, Bluefin, Aurora and Universal Blue.

Debian family — Debian, Ubuntu and its flavours, Mint, LMDE, Pop!_OS, Zorin, elementary, Kali, Parrot, Devuan, Raspberry Pi OS, MX, Deepin, KDE neon and more.

Enterprise — RHEL, CentOS Stream and the rebuilds: Rocky, AlmaLinux, Oracle Linux and others. Arch family — Arch, Manjaro, EndeavourOS, Garuda, CachyOS, ArcoLinux, RebornOS, Archcraft. Amazon Linux, headless only. openSUSE is still under test.

Refused by design, each with a reason the script prints: SteamOS, Artix, Parabola, Gentoo, Slackware, NixOS, Guix, Alpine, Void, Clear Linux, Solus, Qubes, Mageia, OpenMandriva, Chimera and the transactional openSUSE variants.

Choose what you want and this page writes the command. Nothing runs here and nothing leaves your browser.

Run Terminal as Administrator — the script stops without it. It detects your build, applies the Windows 10 or 11 tweaks, then asks which profile to install and installs it with winget.

$ bash <(curl -s https://setup.carino.systems/macos.sh)

Installs Homebrew if missing, then a Basic, Gaming, Corporate or FOSS profile. Apple Silicon and Intel.

Smart Detection

Identifies your OS, distribution and hardware, then installs what matches.

Eight Languages

Installer menus in English, Japanese, Russian, Spanish, Finnish, Chinese, Korean and Hebrew.

Purpose-Built

15 profiles — Gaming, Corporate, Development, Design, Cybersecurity, Medical Imaging and more.

Available Arguments
Flag Action
quickTechnical Setup, then the basic user, system and support packages plus the basic and Google flatpaks.
simpleRuns the Technical Setup only.
serverMinimal server setup with essential dev tools. Skips the full Technical Setup.
nvidia/amd/intelForces specific graphic driver installation.
desktopOpens a menu to select a new Desktop Environment.
svpInstalls Smooth Video Project for frame-interpolated playback.
distroboxInstalls Distrobox containers for other distros.
protonInstalls the latest ProtonGE release.
librewolfAdds the LibreWolf repository and installs it. Fedora and Debian families only.
anydeskEnables Flathub and installs the AnyDesk and RustDesk flatpaks.
anydesk-repoAdds the official AnyDesk repository and installs it natively.
shareMounts a Windows/CIFS share at ~/WinFiles.
no argumentOpens the interactive menu, where option 5 updates the system.
